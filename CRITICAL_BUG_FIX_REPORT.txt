🔍 ROOT CAUSE ANALYSIS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Component: TextInput.tsx (and SelectInput.tsx, TextArea.tsx)

Issue:
  • Components extended React.InputHTMLAttributes<HTMLInputElement>
  • Used spread operator (...props) for all attributes
  • Parent component passed onChange callback expecting string value
  • Component received event object, tried to display it
  • Result: "[object Object]" displayed in inputs

Code Flow:
  1. Parent calls: onChange={(value) => updateFormData({ fullName: value })}
  2. Input fires: onChange event (event object)
  3. Spread props passed event to parent
  4. Parent receives event object instead of string value
  5. Form displays: "[object Object]"


✅ SOLUTION IMPLEMENTED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Component: TextInput.tsx
─────────────────────────────────────────────────────────────────────────────

BEFORE:
┌─────────────────────────────────────────────────────────────────────────┐
│ interface TextInputProps extends React.InputHTMLAttributes<...> {       │
│   label: string;                                                        │
│   error?: string;                                                       │
│ }                                                                       │
│                                                                         │
│ export const TextInput = ({ label, id, error, ...props }) => (         │
│   <input {...props} />  // ❌ Passes event to parent                   │
│ )                                                                       │
└─────────────────────────────────────────────────────────────────────────┘

AFTER:
┌─────────────────────────────────────────────────────────────────────────┐
│ interface TextInputProps {                                              │
│   label: string;                                                        │
│   value: string;                                                        │
│   onChange: (value: string) => void;  // ✅ Expects string             │
│   // ... other explicit props                                           │
│ }                                                                       │
│                                                                         │
│ export const TextInput = ({ value, onChange, ... }) => {               │
│   const handleChange = (e) => onChange(e.target.value); // ✅ Extract  │
│   return <input value={value} onChange={handleChange} />               │
│ }                                                                       │
└─────────────────────────────────────────────────────────────────────────┘
