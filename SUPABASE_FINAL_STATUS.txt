DATABASE SCHEMA:
────────────────────────────────────────────────────────────────────────────
Table: applications
  - 32 columns storing complete application data
  - Foreign key to application_files
  - Status tracking (pending/reviewed/shortlisted/rejected)
  - Content comfort flags (5 boolean fields)
  - File count tracking
  - Timestamps and audit fields

Table: application_files
  - 8 columns for file metadata
  - Links to applications via foreign key
  - Cascade delete configured
  - MIME type and size storage
  - Upload timestamps

Table: audit_log
  - 7 columns for admin action tracking
  - Previous/new value logging
  - User attribution
  - Timestamps

INDEXES (8 total):
  - applications.email - Fast email lookups
  - applications.age_group - Filter by age group
  - applications.status - Filter by status
  - applications.created_at - Sort by date
  - application_files.application_id - File retrieval
  - application_files.file_type - Filter by type
  - application_files.uploaded_at - Sort uploads
  - audit_log.application_id - Audit trail lookup

STORAGE:
  - Bucket: applications (100GB capacity)
  - Organization: /{app-uuid}/{file-type}/{timestamp}_{random}.{ext}
  - Policies: Public INSERT and SELECT

================================================================================
  GETTING STARTED (3 STEPS)
================================================================================

STEP 1: CREATE SUPABASE PROJECT (5 minutes)
────────────────────────────────────────────────────────────────────────────
1. Go to https://app.supabase.com
2. Create new project
3. Copy Project URL
4. Copy anon public key
5. Run SUPABASE_SETUP.sql in SQL Editor
6. Create storage bucket named "applications"

STEP 2: CONFIGURE ENVIRONMENT (2 minutes)
────────────────────────────────────────────────────────────────────────────
1. Create .env.local file
2. Add VITE_SUPABASE_URL=https://your-project.supabase.co
3. Add VITE_SUPABASE_ANON_KEY=your-key-here

STEP 3: TEST & DEPLOY (3 minutes)
────────────────────────────────────────────────────────────────────────────
1. npm run dev
2. Fill form and submit
3. Check Supabase Dashboard
4. Deploy to AWS Amplify
